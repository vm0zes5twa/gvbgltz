What tests are used to evaluate sleep disorders?

Reviewed by Yoshinori Abe, MD

Internal Medicine

Doctors diagnose sleep disorders using several key tests. The most common is polysomnography (a sleep study), which records brain waves, heart rate, breathing, oxygen levels, and eye and leg movements during sleep. Other tools include the Multiple Sleep Latency Test (MSLT) to measure daytime sleepiness, home sleep apnea testing, and actigraphy, which tracks sleep-wake patterns using a wearable device. Doctors may also review sleep diaries and medical history to identify the underlying issue.

Common Tests for Sleep Disorders:

Polysomnography (PSG): This is a detailed test done overnight that helps doctors see how a person sleeps. It checks brain activity, breathing, and other body functions.

Home Sleep Apnea Testing (HSAT): This is a simpler test that can be done at home. It mainly checks for sleep apnea, which is when someone stops breathing for short periods during sleep.

Multiple Sleep Latency Test (MSLT): This test helps understand how quickly someone falls asleep in a quiet environment during the day. It is often used to diagnose narcolepsy.

Maintenance of Wakefulness Test (MWT): This measures how well a person can stay awake. It is often used for people who need to stay alert for work.

These tests help doctors figure out what might be causing sleep problems so they can suggest the best treatment.
